

CampusFind

A campus Lost & Found web application that helps students report, search, match, verify, and recover lost and found items.

About the Project

CampusFind is a web application designed to make it easier for students to report lost or found belongings on campus.

It provides a central Lost & Found Board where students can search and filter reported items, receive possible-match notifications, verify ownership, and mark items as returned.

Main Features

- Report Lost items
- Report Found items
- Store item details using Firebase Firestore
- View Lost & Found items
- Search by item name, description, or location
- Filter by Lost/Found type
- Filter by category
- Filter by item status
- Display item images
- View complete item details
- Contact the reporter
- Detect possible Lost and Found matches
- Show possible-match notifications
- Verify ownership
- Mark items as Returned
- Update returned items to Resolved
- Responsive design for desktop and mobile

Project Flow

Report → Save → Display → Search/Filter → Match → Notification → Verify Ownership → Contact → Mark Returned → Resolved

How It Works

1. A student reports a Lost or Found item.
2. The item details are saved in Firebase Firestore.
3. The item appears on the Lost & Found Board.
4. Students can search and filter the available items.
5. CampusFind checks Lost and Found items for possible matches.
6. A possible-match notification is displayed.
7. Ownership can be verified using the reported item details.
8. The item can be marked as Returned.
9. The item status is updated to Resolved.
