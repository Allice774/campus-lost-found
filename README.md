# Campus Lost & Found Board

## About the Project

Campus Lost & Found Board is a web application that helps students report and find lost or found items on campus.

## Main Features

- Report Lost items
- Report Found items
- Store item details
- View Lost & Found items
- Search for items
- Filter by Lost/Found and category
- View complete item details
- Contact the reporter
- Mark items as Resolved/Returned
- Responsive design for desktop and mobile

## Technology Stack

- HTML
- CSS
- JavaScript
- Firebase
- GitHub

## Project Flow

*Report → Save → Display → Search/Filter → View Details → Contact → Resolve*
